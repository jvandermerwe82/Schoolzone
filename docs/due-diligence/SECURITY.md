# SchoolZone — Security and Safeguarding Diligence

## Sensitive domain

SchoolZone handles child/learner information. Security diligence must therefore cover both technical access controls and safeguarding/consent operating processes.

## Current engineering boundaries

- canonical learner state is server-controlled in cloud mode;
- local storage is resilience support;
- AI tutor is not learner-state authority;
- support adaptation does not diagnose health/neurodevelopmental conditions.

## Required buyer evidence

Before final handover:
- data classification and retention schedule;
- parent/guardian consent flow where applicable;
- teacher/school role and access boundaries;
- secrets/environment register;
- backup/restore access controls;
- incident response contacts/process;
- deletion/export behavior;
- third-party AI/email provider data-processing review.

## Current position

This pack does not claim that all legal/privacy/safeguarding reviews are complete. It identifies the engineering boundary and evidence that must accompany a transaction.
